# Adolescent Driver Safety Monitor

[View this project's Source Code on GitHub](https://github.com/PragnyaVijayan/INRIX23)

### Project Overview
> A mobile application utilizing INRIX telemetry data that monitors teen driver behavior in real-time. It accurately identifies harsh acceleration, braking, and speeding anomalies, automatically alerting parents to intervene. Won 2nd place at the INRIX Hackathon 2023.
