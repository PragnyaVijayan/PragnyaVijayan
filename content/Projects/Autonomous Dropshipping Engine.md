# Agentic AI Autonomous Dropshipping

[View this project's Source Code on GitHub](https://github.com/PragnyaVijayan/sundai-dropshipping)

### Project Overview
> An autonomous, modular e-commerce pipeline utilizing Agentic AI to manage end-to-end dropshipping life-cycles. It handles dynamic market research, WooCommerce product listing, ad creative generation via HuggingFace APIs, and CJ Dropshipping order fulfillment completely passively.
