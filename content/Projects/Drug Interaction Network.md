# Clinical Drug-to-Drug Interaction Network

[View this project's Source Code on GitHub](https://github.com/PragnyaVijayan/Drug-to-Drug-Interactions)

### Project Overview
> A focused web-scraping tool that builds a comprehensive drug interaction database continuously pulled from Drugs.com. The data is visualized using dynamic network graphs and accessible through a streamlined user interface to quickly identify contraindications.
