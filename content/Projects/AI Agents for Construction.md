[View this project's Source Code on GitHub](https://github.com/sohan2000/ai-agents-for-construction)

### Project Overview
> A multi-agent system designed for automating complex construction project management using the Masumi Cardano blockchain. It intelligently handles critical life-cycles such as decentralized bidding, automated scheduling, secure payments, and dynamic progress tracking to ensure efficient, transparent, and secure workflows.
