# Ascend - AI Freelancer Bidding Engine

[View this project's Source Code on GitHub](https://github.com/PragnyaVijayan/AWS_Hack_2024)

### Project Overview
> A dedicated AI tool built for freelancers. It analyzes current market rates, summarizes complex contracts, and automatically drafts intelligent negotiation emails using AWS services, Hugging Face, GPT-3, and visual analytics dashboards. Won 3rd place at the AWS x INRIX Hackathon 2024.
